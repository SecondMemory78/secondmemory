# ADR-0003. Правила лекарственной безопасности

## Контекст
Справочник врача задаёт жёсткие правила (лист «Правила_замены», «Перекрестные_реакции»).

## Решение (инварианты, см. CONTEXT.md)
- Никаких автозамен: `auto_substitution_allowed=FALSE`, `physician_review_required=TRUE`.
- Перекрёстность по структуре (R1-цепь), не по классу.
- Комбинации раскладываются на компоненты; учитываются скрытые компоненты (PEG и т.п.).
- Тошнота/ЖКТ ≠ аллергия; фенотип фиксируется отдельно.
- Наша проверка аллергий **предупреждает и требует причину** (в аудит), но не блокирует
  и не заменяет. Текущий упрощённый групповой матч будет заменён на структурные правила
  из справочника (тикет T8).

## Статус
Принято. Согласование модуля allergy со справочником — тикет T8.
