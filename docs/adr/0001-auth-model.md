# ADR-0001. Модель входа и роли

## Контекст
Сейчас вход — «любой PIN» (заглушка), `DOCTOR_ID = 1` захардкожен во всех роутерах.
Это блокирует реальную безопасность, мультиврача и 152-ФЗ.

## Решение
- Аккаунт = email + пароль (хеш). Первый вход на устройстве и любой вход на новом
  устройстве → одноразовый код на почту (2FA). SMS — позже как альтернатива.
- Десктоп: логин+пароль+код с почты; галочка «запомнить устройство» → токен 90 дней,
  перезапуск НЕ выкидывает.
- Быстрый локальный разблок уже авторизованного приложения: **биометрия
  (WebAuthn/passkey на вебе/десктопе; нативный плагин в Capacitor) ИЛИ PIN** — как в банках.
- Роли: doctor (свои медданные), support (только чаты), admin (аналитика + врачи + чаты,
  но карту пациента открыть нельзя).
- В коде вводится шов `current_doctor` вместо `DOCTOR_ID`.

## Статус
Принято. Реализация — тикеты T3/T4.
