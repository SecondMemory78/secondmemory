# ADR-0004. Визит (encounter) и множественные диагнозы

## Контекст
Сейчас приём, протокол, назначения, документы разрознены. Диагноз у пациента один.

## Решение
- Вводим сущность **Визит (Encounter)**: открывается при «начать приём», к ней
  привязываются наблюдения/заметки/назначения/протокол/документы этого посещения.
  Вкладка «История» = список визитов.
- **Множественные диагнозы**: у пациента список PatientDiagnosis (код МКБ + версия +
  формулировка + статус + дата), один «основной» в шапке. История изменений не затирается.
- Диагнозы выбираются из справочника `icd_urology.json` (срез по специальности).

## Статус
Принято. Реализация — тикеты T5 (encounter), T6 (диагнозы).
